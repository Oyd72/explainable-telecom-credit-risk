# Monitoring outputs

This directory stores aggregate, privacy-safe monitoring evidence generated by the project.

Expected outputs include:

- `population_summary.json`
- `feature_drift.csv`
- `latest_status.json`
- `evidently_drift.html`
- `evidently_drift.json`

Row-level source data remain outside the repository.

The historical comparison uses the development population as reference and the later holdout as comparison. In a live system, the same label-free checks would run on new scored batches, while performance metrics would wait for trustworthy outcomes.
